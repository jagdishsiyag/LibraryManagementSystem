# Library Management System (C++)

A console-based Library Management System built with Object-Oriented
Programming and file handling in C++.

## Features
- Add and display books
- Search books by title or author (case-insensitive, partial match)
- Register members and view them
- Issue and return books with per-member borrowing limit
- Persistent records in `books.txt`, `members.txt`, `issues.txt`

## OOP Concepts Used
- Encapsulation, Abstraction, Inheritance, Polymorphism, Composition

## Build & Run

```bash
g++ LibraryManagementSystem.cpp -o library
./library
